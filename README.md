# Personal webpage

Static site (`index.html`, `style.css`) plus the LaTeX CV (`main.tex`).

- Rebuild the CV PDF: `make cv` → `CV_Pharuj_Rajborirug.pdf`
- Preview the site: `python3 -m http.server` then open http://localhost:8000
- Deploy: push to GitHub and enable Pages (Settings → Pages → branch `main`, root).
